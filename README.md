## Engineering Work

### Leafiyo — AI Ebook Generation SaaS

> Full-stack SaaS platform for generating and selling AI-authored ebooks, illustrated books, and mini-novels. Built for the global francophone market with French, English, Spanish, and German language support.
>
> **Role:** Full-Stack Developer — Next.js frontend, API routes, AI pipeline integration, Supabase backend, payment gateway setup, and admin panel

**Core product flow:**
- Keyword input → Claude Sonnet 4 generates 5 curated title/description concepts
- User selects a tier (Basic / Mid / Premium), picks from 3 AI-generated covers, then triggers generation
- "Leafiyo Stories" mode produces illustrated books with character-consistent image generation across all pages
- Credit-based monetisation: Stripe for international markets, CinetPay for francophone Africa

**Engineering decisions worth noting:**
- Generation pipeline runs 60–120s — API returns `job_id` immediately; frontend polls `/status/:jobId` asynchronously to avoid Vercel's 60s function limit
- Character consistency across illustrations enforced by injecting the character card verbatim into every sequential image prompt (no parallel calls)
- Atomic credit operations: every deduction, refund, and grant writes to both `credit_balance` and `credit_transactions` in a single DB transaction — no partial states
- Admin panel covers KPI dashboards, promo code management, payment gateway toggles, and Meta Pixel / GA4 / GTM configuration

**Stack:** `Next.js 14 (App Router)` · `Supabase (PostgreSQL)` · `Claude Sonnet 4 (Anthropic)` · `Gemini Image via fal.ai` · `Stripe` · `CinetPay` · `Brevo` · `Vercel`

### DOS2-AI — AI-Powered Condo Management Platform

> Multi-tenant property management SaaS for Ontario condominium corporations — automating email triage, resident communication, governance Q&A, and legal document generation.
>
> **Role:** Frontend Engineer — UI architecture, component design, backend API integration (React/Vite · FastAPI)

**System capabilities:**
- **WhatsApp AI Concierge** — LangGraph state machine identifies residents by phone hash, routes by role and intent: balance inquiries, amenity booking, maintenance complaints, visitor parking, emergency escalation
- **AI Email Triage** — Polls shared Gmail inbox every 5 minutes; classifies by category and risk level, scores priority, generates action summaries via Groq (llama-3.3-70b)
- **RAG-Powered Q&A** — Gemini embeddings (768-dim, pgvector) over governance documents; residents and managers query building rules in plain language
- **Status Certificate Engine** — Auto-populates Ontario SC forms from live database, corporation profile, and RAG search; generates final XFA PDF via XML injection
- **Emergency Detection** — Inbound WhatsApp messages classified for emergency signals; triggers a 60-second cancellable manager alert

**Stack:** `React 18 / Vite` · `FastAPI (Python 3.12)` · `PostgreSQL + pgvector` · `LangGraph` · `Groq` · `Gemini` · `WhatsApp Cloud API` · `GCP Cloud Run` · `Docker`
